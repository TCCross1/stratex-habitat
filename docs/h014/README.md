## Operating model (immutable)
Core performs the work · Passport remembers the home · Habitat sustains the relationship.

## Foundational rules
1. One shared spatial model; Interior/Exterior/Systems are views, not separate apps.
2. One property coordinate frame; PLANNING tolerance by default; never survey-grade unless proven.
3. One truth taxonomy on every datum; UI distinguishes states by color + icon + label.
4. Habitat never writes canonical truth; reads via the projection boundary; write-back is Core/Passport.
5. Single governed publication path; HARD blockers cannot be overridden; no fabricated data.
