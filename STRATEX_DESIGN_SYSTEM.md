# STRATEX DESIGN SYSTEM™ (SDS)
## THE SINGLE SOURCE OF TRUTH FOR THE STRATEX ECOSYSTEM

---

## 1. MISSION & VISION

### 1.1 Mission Statement
The Stratex Design System (SDS) is the definitive visual, interactive, and structural standard for all products across the Stratex ecosystem. It serves as the single source of truth for visual components, interactions, animations, spacing rules, typography, statuses, colors, 3D visualizations, and accessibility requirements. 

This design system ensures that a operator or homeowner can transition seamlessly between **Core**, **Passport**, **Habitat**, **CENTCOM**, **Design Studio**, **Project Opportunity Engine**, **Reports**, **Operator Mobile**, and **Contractor Portal** without learning a new interface.

### 1.2 Core Archetype: Control Room Dashboard
We explicitly reject standard SaaS aesthetics, playful rounded bubbles, or purple/blue generic AI templates. 
* **Archetype:** Electric & Neon + Swiss & High-Contrast (Investor-Grade / Command Center).
* **Vibe:** Technical, futurist, dense, and precise. It is built to feel like a premium dark control-room dashboard.
* **Linguistic Constraint:** *Always explain, never alarm.* Every technical reading must translate complex analytics into clear, supportive, and educational guidance.

---

## 2. ENGINEERING LAW

> **No UI component shall be created outside the official Design System.**
> **Every interface must use approved tokens, components, and interaction patterns.**

Any deviation from this system violates CENTCOM Directive 014. If a custom layout is required, it must be generated by composing existing tokens or through a formal expansion amendment to this system.

## 3. DESIGN SYSTEM NAVIGATION (THE SUITE)

The Stratex Design System is split into modular, interconnected directives:

1. **[Design Tokens (DESIGN_TOKENS.md)](./DESIGN_TOKENS.md)**  
   *The structural atoms: spacing, grid, radius, elevation, borders, opacity, glow, animation timing, motion curves, breakpoints, and z-index.*
2. **[Color System (COLOR_SYSTEM.md)](./COLOR_SYSTEM.md)**  
   *The functional palette: primary, secondary, status, dark mode, print-safe colors, and color-blind accessibility standards.*
3. **[Typography (TYPOGRAPHY.md)](./TYPOGRAPHY.md)**  
   *Font families (Outfit, IBM Plex Sans, JetBrains Mono), sizing hierarchy, and custom character settings for high data density.*
4. **[Component Library (COMPONENT_LIBRARY.md)](./COMPONENT_LIBRARY.md)**  
   *A complete React component inventory from buttons and command panels to complex DNA cards and health gauges.*
5. **[Iconography (ICONOGRAPHY.md)](./ICONOGRAPHY.md)**  
   *The engineering, property, contractor, inspection, and evidence symbols, alongside confidence and relationship indicators.*
6. **[Motion Design Guidelines (MOTION_GUIDELINES.md)](./MOTION_GUIDELINES.md)**  
   *Interactive transitions, skeleton states, timeline visualizations, and 3D hover/selection animation curves.*
7. **[3D Visual Language (DIGITAL_TWIN_VISUALS.md)](./DIGITAL_TWIN_VISUALS.md)**  
   *Digital Twin standards: orbiting camera behavior, thermal overlays, property DNA overlays, and knowledge graph mapping.*
8. **[Report Design System (REPORT_DESIGN_SYSTEM.md)](./REPORT_DESIGN_SYSTEM.md)**  
   *Premium layouts for PDF outputs, executive briefs, insurance reviews, and interactive digital contractor reports.*
9. **[Responsive Standards (RESPONSIVE_STANDARDS.md)](./RESPONSIVE_STANDARDS.md)**  
   *Viewport behavior across mobile, tablet, desktop, and ultra-wide screens, touch optimization, and keyboard navigation rules.*
10. **[Implementation & Migration Guide (IMPLEMENTATION_GUIDE.md)](./IMPLEMENTATION_GUIDE.md)**  
    *Tailwind configurations, CSS variables, Storybook structure, token build pipelines, and versioning/migration strategies.*

## 5. SUCCESS CRITERIA

A Stratex interface is successful if and only if:
1. **Zero Aesthetic Drift:** The system looks like it was designed by a single designer and implemented by a single developer.
2. **Technical Mastery:** Layouts feel robust, scientific, and authoritative, inspiring complete trust.
3. **Frictionless Motion:** Navigation, loading states, and 3D interactions are crisp, intentional, and high-performance.
4. **Linguistic Reassurance:** Diagnostics and status changes are educational and actionable rather than fear-inducing.
